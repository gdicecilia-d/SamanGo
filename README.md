# SamanGo ✨
¡Bienvenido al repositorio de SamanGo! Esta es una plataforma moderna, desarrollada con Flutter, diseñada especialmente para optimizar la experiencia dentro del campus de la Universidad Metropolitana. Es rápida, eficiente y cuenta con una interfaz visual intuitiva.

### Tecnologías Utilizadas 🛠️

Para garantizar un rendimiento óptimo y una arquitectura escalable, el proyecto implementa:

- Framework: Flutter y Dart para el desarrollo del frontend multiplataforma en móvil y web.
- Hosting y Backend: Firebase para el despliegue estable de la versión web y servicios en la nube.
- Pasarela de Pagos: Integración con la API de PayPal para transacciones e inscripciones seguras.
- Inteligencia Artificial: Conexión con la API de Gemini para potenciar el chatbot interactivo.
- Control de Versiones: Git y GitHub para la gestión del repositorio y el trabajo colaborativo.
  
### Características Principales 📱 
- Interfaz Intuitiva: Un diseño limpio basado en componentes visuales interactivos.
- Multiplataforma Real: Totalmente optimizado para funcionar tanto en dispositivos móviles como en navegadores web.
- Asistente Virtual Inteligente: Un chatbot integrado (impulsado por Gemini) listo para responder dudas de forma inmediata dentro de la plataforma.

### Ejecución local 💻

```bash
flutter pub get
flutter run -d chrome --web-port 5000
```
